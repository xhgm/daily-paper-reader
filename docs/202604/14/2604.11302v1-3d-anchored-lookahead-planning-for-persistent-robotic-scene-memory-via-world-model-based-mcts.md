## 摘要
我们提出了 3D 锚定前瞻规划（3D-ALP），这是一种用于机器人操控的 System 2 推理引擎，它将蒙特卡洛树搜索（MCTS）与 3D 一致的世界模型相结合，并将其作为展开预言机（rollout oracle）。与仅根据当前相机帧评估动作的反应式策略不同，3D-ALP 维持一个持久的相机到世界（c2w）锚点，该锚点在发生遮挡时依然存在，从而能够对不再直接可见的物体位置进行精确的重新规划。在需要空间记忆的 5 步序列到达任务（实验 E3）中，3D-ALP 在需要记忆的步骤上实现了 0.650 ± 0.109 的成功率，而贪婪反应式基准仅为 0.006 ± 0.008（Δ=+0.645）；在第 5 步的成功率达到 0.822，而贪婪基准为 0.000。消融实验（30 个回合，3 个随机种子）表明，树搜索空间记忆是主要的驱动因素（+0.533，贡献了 82% 的增益），而更深的前瞻规划也带来了额外收益（+0.111，贡献了 17%）。我们还识别并解决了将 UCT-MCTS（应用于树的置信上限）应用于连续机器人操控时的四种结构性失效模式。

## Abstract
We present 3D-Anchored Lookahead Planning (3D-ALP), a System 2 reasoning engine for robotic manipulation that combines Monte Carlo Tree Search (MCTS) with a 3D-consistent world model as the rollout oracle. Unlike reactive policies that evaluate actions from the current camera frame only, 3D-ALP maintains a persistent camera-to-world (c2w) anchor that survives occlusion, enabling accurate replanning to object positions that are no longer directly observable. On a 5-step sequential reach task requiring spatial memory (Experiment E3), 3D-ALP achieves 0.650 0.109 success rate on memory-required steps versus 0.006 0.008 for a greedy reactive baseline (Δ=+0.645), while step 5 success reaches 0.822 against 0.000 for greedy. An ablation study (30 episodes, 3 seeds) isolates tree search spatial memory as the primary driver (+0.533, 82% of gain) with additional benefit from deeper lookahead (+0.111, 17%). We also identify and resolve four structural failure modes in applying UCT-MCTS (Upper Confidence Bounds applied to Trees [10]) to continuous robotic manipulation.

### 1. 核心问题与研究动机
*   **核心问题**：现代机器人操控系统（如 VLA 模型）大多属于“System 1”反应式策略，仅依赖当前相机帧。当目标物体被遮挡或机器人移开视线后，系统会因失去空间记忆而无法返回之前的目标位置。
*   **研究动机**：人类具备“物体恒存性”认知，即知道看不见的物体依然存在于原处。作者希望为机器人引入“System 2”推理引擎，通过 3D 空间锚定和前瞻规划，使机器人在复杂、多步且存在遮挡的任务中保持持久的场景记忆。

### 2. 方法论
3D-ALP 结合了蒙特卡洛树搜索（MCTS）和 3D 一致性世界模型，核心组件包括：
*   **持久化 3D 锚点（Persistent 3D Anchor）**：通过机器人正向运动学（FK）实时更新相机到世界（c2w）的坐标变换。即使物体被遮挡，其在世界坐标系中的位置仍保留在 MCTS 搜索树中。
*   **3D 一致性世界模型（InSpatio-WorldFM）**：作为 MCTS 的推演预言机（Oracle），根据给定的 c2w 查询渲染预测的未来视觉帧。
*   **混合几何-语义评分器（Hybrid Scorer）**：针对视觉大模型（VLM）存在的“深度盲区”（即 2D 像素重叠不代表 3D 接触），将语义评分与运动学深度惩罚相结合，强制规划器关注几何上的真实接近。
*   **针对连续操控的 MCTS 改进**：解决了 UCT-MCTS 在机器人任务中的四个失效模式：
    1.  **零动作剥削陷阱**：改用 Max-Q 值选择而非访问次数。
    2.  **树深度衰减**：在根节点移动后递归重置深度。
    3.  **标准平均惩罚**：使用 Max-MCTS 进行反向传播，避免优秀路径被平庸分支稀释。
    4.  **UCB1 常数失配**：将探索常数 $c$ 从 1.414 调整为 0.02，以匹配连续运动学得分。

### 3. 实验设计
*   **场景与任务**：在 MuJoCo 仿真环境中使用 Franka Panda 机械臂执行 **E3 实验**（5 步序列到达任务）。前 3 步物体可见，第 4-5 步要求机器人返回之前已移出视野的位置。
*   **基准方法（Benchmark）**：
    *   **Greedy Reactive Baseline**：贪婪反应式基准，每步选择当前距离最小的动作。

*   **对比指标**：成功率（Success Rate, SR），特别关注需要记忆的步骤（Steps 4-5）。

### 5. 实验数量与充分性
*   **实验规模**：进行了 30 个回合（Episodes）× 3 个随机种子的测试。
*   **消融实验**：设计了针对树深度（D=1 vs D=2）和记忆机制的消融，清晰地分解了性能增益的来源。
*   **充分性评价**：实验设计较为严谨，通过 Phase 0-1 验证了几何一致性和运动学桥接的准确性。虽然样本量（30 episodes）在仿真实验中不算巨大，但其在记忆任务上的性能差异（65% vs 0.6%）具有显著的统计学意义。

### 6. 主要结论与发现
*   **记忆鸿沟**：在需要记忆的步骤中，反应式基准几乎完全失效（SR 0.6%），而 3D-ALP 保持了 **65%** 的成功率。
*   **增益分解**：消融研究显示，**树搜索空间记忆**是主要驱动力（贡献了 82% 的性能提升），而**深度前瞻**（D=2）在最难的链式记忆步骤（第 5 步）中额外贡献了 17% 的增益。
*   **VLM 局限性**：实验证实了 VLM 往往忽略精细视觉细节而倾向于语义锚点，导致其在缺乏语言标签的精确运动学姿态上评分“平坦化”。

### 7. 优点
*   **架构创新**：将 3D 几何锚点引入 MCTS，解决了机器人领域长期存在的遮挡下空间记忆难题。
*   **工程落地**：识别并修复了经典 MCTS 算法在连续机器人控制中的四个关键结构性问题，具有很强的实用参考价值。
*   **模块化**：系统组件（世界模型、评分器、规划器）解耦，易于替换更先进的模型（如 JEPA）。

### 8. 不足与局限
*   **渲染瓶颈**：生成式世界模型的渲染速度较慢（2.4s/帧），限制了实时规划的搜索深度。
*   **视觉评分缺陷**：现有的 VLM（如 Florence-2）在合成渲染图上的深度感知能力不足，仍需依赖几何预言机或混合评分器。
*   **环境限制**：目前仅在 MuJoCo 仿真中验证，尚未在真实物理机器人上进行大规模测试，且仅限于单臂操作。
*   **任务复杂度**：实验主要集中在“到达”任务，对于更复杂的交互（如抓取、推挤导致的物体位移）下的记忆更新尚待探讨。
