## 摘要
视觉语言模型（VLM）通过将视觉编码器与大语言模型（LLM）相结合，取得了显著的成功。尽管 VLM 在深层 Transformer 堆栈中处理密集的图像 Token（这带来了巨大的计算开销），但持续的图像 Token 处理对其性能是否必要，或者视觉表示是否在从浅层到深层的过程中发生了有意义的演变，在根本上仍不清楚。在这项工作中，我们系统地研究了 VLM 中图像 Token 的功能作用，并表明视觉表示会迅速收敛到有界复杂度状态，即其熵趋于稳定，本征维度发生压缩，且轨迹曲率接近恒定。相比之下，文本表示在不同深度上持续经历实质性的重构。一旦稳定，视觉表示在层与层之间变得在很大程度上可以互换，这表明在更深阶段的额外变换非常有限。此外，深度维度的视觉截断表明，视觉处理的必要性取决于具体任务：单 Token 预测对截断的视觉深度保持相对鲁棒，而多 Token 生成则需要持续访问视觉表示。在确定性解码下，减少视觉深度对中间推理轨迹的扰动比对最终输出的扰动更强烈，这表明图像 Token 对推理结构的影响大于对最终结论的影响。总之，这些发现质疑了“深层视觉处理在 VLM 中普遍必不可少”的假设，挑战了当前多模态 LLM 架构的范式。

## Abstract
Vision Language Models (VLMs) have achieved remarkable success by integrating visual encoders with large language models (LLMs). While VLMs process dense image tokens across deep transformer stacks (incurring substantial computational overhead), it remains fundamentally unclear whether sustained image-token processing is necessary for their performance or visual representations meaningfully evolve from early to later layers. In this work, we systematically investigate the functional role of image tokens in VLMs and show that visual representations rapidly converge to a bounded-complexity regime, \ie their entropy stabilizes, intrinsic dimensionality compresses, and trajectory curvature approaches a near-constant profile. In contrast, textual representations continue to undergo substantial restructuring across depth. Once stabilized, visual representations become largely interchangeable between layers, indicating limited additional transformation in deeper stages. Further, depth-wise visual truncation reveals that the necessity of visual processing is task-dependent, where single-token predictions remain comparatively robust to truncated visual depth, but multi-token generation require sustained access to visual representations. Under deterministic decoding, reducing visual depth perturbs intermediate reasoning trajectories more strongly than final outputs, suggesting that image tokens influence the structure of reasoning more than the ultimate conclusions. Collectively, these findings \textbf{question the assumption} that deeper visual processing is uniformly essential in VLMs, challenging the current paradigm of multimodal LLM architectures.

当前视觉语言模型（VLM）的主流架构（如 LLaVA, Qwen-VL）通常将图像 Token 与文本 Token 一起输入到大型语言模型（LLM）的每一层进行处理。这种做法带来了巨大的计算开销，尤其是图像 Token 数量通常远多于文本。
**核心问题**：图像 Token 在经过 LLM 的深层堆栈时，其表征是否真的在持续演化？在模型的后期层中，持续处理这些图像 Token 是否是维持性能所必需的？
**研究背景**：已有研究发现 VLM 在纯视觉任务上表现不如其视觉编码器，暗示视觉信息在多模态推理中可能未被充分利用。本论文旨在从表征动力学的视角，探究视觉信息的冗余性及其对不同任务的贡献。

### 2. 方法论：核心思想与关键技术
论文通过以下三种实验协议来解构图像 Token 的作用：

*   **表征演化分析（Representational Metrics）**：
    *   **矩阵熵（Matrix Entropy）**：利用冯·诺依曼熵衡量表征的谱集中度，低熵表示信息压缩。
    *   **本征维度（Intrinsic Dimensionality, ID）**：估计局部流形的维度，反映表征的最小描述复杂度。
    *   **轨迹曲率（Trajectory Curvature, TC）**：计算层与层之间更新向量的夹角变化，衡量表征重构的剧烈程度。
*   **层间功能互换性（Layer-wise Interchangeability）**：
    *   构建“混合状态”，将第 $l_a$ 层的图像表征与第 $l_b$ 层的文本表征组合，观察输出语义的变化。如果图像表征在深层是稳定的，那么用浅层表征替换深层表征应不影响结果。
*   **深度截断协议（Depth Truncation Protocol）**：
    *   设定一个截止层 $l_c$，在此层之后移除所有图像 Token，仅让文本 Token 继续在后续层中传播。

### 6. 主要结论与发现
1.  **表征不对称性**：图像 Token 的表征在 LLM 的早期层（约前 1/4 到 1/3）就迅速进入稳定状态（熵和曲率趋于平缓），而文本 Token 在所有层中持续进行剧烈的语义重构。
2.  **功能冗余性**：一旦视觉表征稳定，它们在层间具有高度的可互换性。用第 10 层的图像 Token 替换第 30 层的图像 Token，对最终输出的影响微乎其微。
3.  **任务依赖性**：
    *   **单 Token 任务**（如选择题）对视觉深度不敏感，早期截断仍能保持高精度。
    *   **多 Token 生成**（如描述、推理）对视觉深度高度敏感，需要持续的视觉引导。
4.  **可恢复性**：通过蒸馏微调，截断后的模型可以显著恢复性能，并提高推理效率（主要减少了 Prefill 阶段的计算量）。
5.  **推理链脆弱性**：显式推理（CoT）并不能补偿视觉深度的缺失，反而因为增加了生成步骤而放大了对视觉信息的依赖。

### 7. 优点
*   **视角新颖**：不同于以往单纯做 Token 剪枝（横向减少 Token 数量），本文关注的是“深度冗余”（纵向减少处理层数）。
*   **理论与实践结合**：利用微分几何和信息论指标（曲率、熵）为“为什么可以截断”提供了坚实的理论解释。
*   **效率启示**：为设计更高效的 VLM 提供了明确指导，即可以在 Prefill 阶段之后或在 LLM 深层跳过图像 Token 的计算。

### 8. 不足与局限
*   **微调成本**：虽然证明了微调可以恢复性能，但对于超大规模模型（如 72B+），针对每个截断深度进行微调的成本依然很高。
*   **极端复杂任务覆盖不足**：实验主要集中在描述和基础 VQA，对于需要极高空间分辨率或极细微视觉差异的任务（如医学影像分析、精密工业检测），早期稳定的结论是否依然成立尚存疑问。
*   **架构局限**：研究主要基于 Decoder-only 的 Transformer 架构，对于其他新兴架构（如基于 Mamba 或线性注意力的模型）的适用性未做探讨。
