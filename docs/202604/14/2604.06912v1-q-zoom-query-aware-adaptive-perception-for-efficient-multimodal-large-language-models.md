## 摘要
多模态大语言模型（MLLMs）在文档理解和密集场景感知等细粒度任务中需要高分辨率的视觉输入。然而，当前的全局分辨率缩放范式不加区分地将视觉冗余的 token 注入到具有二次复杂度的自注意力机制中，在忽略空间稀疏性和查询意图的同时，严重制约了推理吞吐量。为了克服这一问题，我们提出了 Q-Zoom，这是一个以高效的“由粗到细”方式运行的查询感知自适应高分辨率感知框架。首先，轻量级动态门控网络（Dynamic Gating Network）在粗粒度全局特征足够时，能够安全地跳过高分辨率处理。其次，对于需要细粒度感知的查询，自蒸馏区域建议网络（SD-RPN）直接从中间特征空间精确地定位与任务相关的感兴趣区域（RoI）。为了高效优化这些模块，门控网络采用一致性感知生成策略来获取确定性的路由标签，而 SD-RPN 则采用完全自监督的蒸馏范式。随后，通过连续时空对齐方案和针对性微调，将密集的局部 RoI 与粗粒度的全局布局无缝融合。大量实验表明，Q-Zoom 建立了领先的帕累托前沿（Pareto frontier）。以 Qwen2.5-VL-7B 作为主要实验平台，Q-Zoom 在文档与 OCR 基准测试上的推理速度提升了 2.52 倍，在高分辨率场景下提升了 4.39 倍，同时保持了基准模型的峰值精度。此外，在配置为最大感知保真度时，Q-Zoom 在上述基准测试中分别超过基准模型峰值性能 1.1% 和 8.1%。这些显著的改进可无缝迁移至 Qwen3-VL、LLaVA 以及新兴的基于强化学习（RL）的图像思考模型。项目页面见 https://yuhengsss.github.io/Q-Zoom/。

## Abstract
MLLMs require high-resolution visual inputs for fine-grained tasks like document understanding and dense scene perception. However, current global resolution scaling paradigms indiscriminately flood the quadratic self-attention mechanism with visually redundant tokens, severely bottlenecking inference throughput while ignoring spatial sparsity and query intent. To overcome this, we propose Q-Zoom, a query-aware adaptive high-resolution perception framework that operates in an efficient coarse-to-fine manner. First, a lightweight Dynamic Gating Network safely bypasses high-resolution processing when coarse global features suffice. Second, for queries demanding fine-grained perception, a Self-Distilled Region Proposal Network (SD-RPN) precisely localizes the task-relevant Region-of-Interest (RoI) directly from intermediate feature spaces. To optimize these modules efficiently, the gating network uses a consistency-aware generation strategy to derive deterministic routing labels, while the SD-RPN employs a fully self-supervised distillation paradigm. A continuous spatio-temporal alignment scheme and targeted fine-tuning then seamlessly fuse the dense local RoI with the coarse global layout. Extensive experiments demonstrate that Q-Zoom establishes a dominant Pareto frontier. Using Qwen2.5-VL-7B as a primary testbed, Q-Zoom accelerates inference by 2.52 times on Document & OCR benchmarks and 4.39 times in High-Resolution scenarios while matching the baseline's peak accuracy. Furthermore, when configured for maximum perceptual fidelity, Q-Zoom surpasses the baseline's peak performance by 1.1% and 8.1% on these respective benchmarks. These robust improvements transfer seamlessly to Qwen3-VL, LLaVA, and emerging RL-based thinking-with-image models. Project page is available at https://yuhengsss.github.io/Q-Zoom/.

#### 1. 核心问题与研究动机
*   **核心问题**：多模态大语言模型（MLLM）在处理高分辨率图像以捕捉细粒度细节（如OCR、文档理解）时，面临计算开销巨大的瓶颈。
*   **研究动机**：
    *   **查询冗余**：并非所有问题都需要高分辨率，简单问题用粗粒度特征即可回答。
    *   **空间冗余**：图像中大部分区域（背景）对回答特定问题是无用的，全局缩放会导致大量无用视觉 Token 进入计算量呈二次方增长的自注意力机制。
    *   **现有方案缺陷**：现有的“训练无关”方法需要多次预填充（Prefilling），而基于强化学习（RL）的方法推理延迟高（需要冗长的思维链解码），且训练极不稳定。

#### 2. 方法论
Q-Zoom 提出了一个**由粗到精（Coarse-to-Fine）**的自适应感知框架，核心技术包括：
*   **动态门控网络（Dynamic Gating Network）**：
    *   在模型中间层插入轻量级路由，判断当前查询是否需要高分辨率。
    *   **一致性感知生成策略**：通过观察模型在不同分辨率下的表现是否一致来自动生成训练标签，无需人工标注。
*   **自蒸馏区域建议网络（SD-RPN）**：
    *   若门控触发，SD-RPN 直接从中间特征空间预测感兴趣区域（RoI）的热力图。
    *   **自监督蒸馏范式**：利用模型内部的交叉注意力图作为伪标签，通过去除“汇点 Token（Sink Tokens）”和“三态标签分配”来去噪，训练 RPN。
*   **时空对齐与融合**：
    *   **连续时空位置编码**：利用多模态旋转位置嵌入（MRoPE），通过时间偏移和空间插值，将局部高分辨率 RoI 重新映射回全局坐标系。
    *   **针对性后微调（Post-SFT）**：在挖掘出的“硬样本”（即加入 RoI 后反而出错的情况）上进行微调，教模型如何融合全局布局与局部细节。

*   **数据集与场景**：
    *   **文档与 OCR 任务**：DocVQA, InfoVQA, ChartQA, OCRBench, TextVQA。

    *   **通用 QA 任务**：MMStar, MME（用于验证通用能力是否受损）。
*   **基准模型（Backbones）**：Qwen2.5-VL (3B/7B), Qwen3-VL (4B), LLaVA-1.5 (7B/13B), 以及基于 RL 的 ZwZ-Qwen 模型。
*   **对比方法**：包括暴力缩放（S²）、训练无关启发式方法（ViCrop）、基于 RL 的动态路由（AdaptVision, Thyme, DeepEyes）。

*   **硬件环境**：论文提到推理吞吐量是在单张 **NVIDIA RTX A6000 GPU** 上测量的。

#### 5. 实验数量与充分性
*   **实验规模**：论文在 3 个模型家族、多个参数规模（3B 到 13B）上进行了验证，涵盖了 10 多个主流基准测试。
*   **消融实验**：非常充分，涵盖了模块有效性（RPN/SFT/Gate）、Backbone 深度选择、RPN 层数、数据规模、伪标签阈值、以及一致性采样策略的对比。
*   **客观性**：通过与最新的 SOTA 方法（如 2025/2026 年的预印本方法）对比，并展示了帕累托前沿曲线，证明了其在效率与精度平衡上的优越性。

#### 6. 主要结论与发现
*   **性能领先**：Q-Zoom 在 Qwen2.5-VL-7B 上实现了 **2.52倍（文档类）**和 **4.39倍（高分辨率类）**的推理加速。
*   **Token 节省**：在保持或超越基准模型峰值精度的前提下，视觉 Token 消耗减少了 **53.0% 至 73.2%**。
*   **精度提升**：在配置为最高保真度时，其性能甚至超过了使用 4096 个 Token 的暴力基准模型，尤其在细粒度 OCR 任务上表现突出。
*   **兼容性**：Q-Zoom 可以作为插件应用于 RL 训练的模型，并进一步提升其性能和效率。

#### 7. 优点
*   **高效性**：在单次预填充（Prefilling）过程中完成所有决策，避免了多次推理或冗长的文本解码。
*   **低成本训练**：采用自蒸馏和自动标签生成，完全不需要人工标注的坐标数据。
*   **空间一致性**：通过创新的时空对齐方案，解决了局部裁剪图像与全局背景脱节的问题。

#### 8. 不足与局限
*   **基座依赖性**：在 LLaVA-1.5 等低分辨率基座模型上，由于原始分辨率过低，门控网络几乎总是触发高分辨率分支，导致加速效果不如在原生支持动态分辨率的模型（如 Qwen）上显著。
*   **位置编码限制**：Post-SFT 阶段的对齐高度依赖于 MRoPE 等先进位置编码，对于不支持此类编码的老旧架构，融合效果可能受限。
*   **应用限制**：虽然在静态图像上表现优异，但尚未讨论在视频理解等更复杂时空序列任务中的扩展性。
